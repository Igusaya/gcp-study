GCP 学習ロードマップ

目標：Associate Cloud Engineer（ACE）の合格と、実務で GCP を使ったプロジェクトをリードできるようになること

Phase 1　参画前の土台づくり

実務の会話についていくための土台を、短期間で固めるフェーズです。ここで扱う内容は、ACE の中心範囲とも大きく重なります。

#トピック内容主な ACE 分野状態
0環境準備 gcloud の configuration、学習用プロジェクト、予算アラート 1. 環境のセットアップ 完了
1リソース階層と課金 組織・フォルダ・プロジェクト、IAM の継承、組織ポリシー、請求先アカウント 1. 環境のセットアップ 完了
2IAM プリンシパル・ロール・許可ポリシーと拒否ポリシー、サービスアカウント、最小権限 4. アクセスとセキュリティ 完了
3ネットワーク基礎 VPC ネットワーク、サブネット、ファイアウォール ルール、外部 IP・内部 IP、Cloud NAT、IAP、共有 VPC 2. 計画と実装 完了
4実行環境の選び方 Compute Engine / GKE / Cloud Run / Cloud Run functions / App Engine の使い分け、Spot VM、マネージド インスタンス グループ 2. 計画と実装 完了
5Cloud Run ハンズオン コンテナのビルドとデプロイ、Artifact Registry、リビジョンとトラフィックの分割、呼び出しの認証、サービス ID 2. 計画と実装 学習中
6データストア概観 Cloud SQL / Firestore / Cloud Storage / BigQuery の使い分け 2. 計画と実装 未着手
7運用 Cloud Logging / Cloud Monitoring、エラー調査の基本 3. 運用の確保 未着手

Phase 2　参画後

  • プロジェクトで使っているサービスを優先して学ぶ。教材の内容は参画後に組み直す
  • 並行して、Phase 1 でカバーしきれなかった ACE の範囲を補う

Phase 3　ACE 仕上げ

  • 公式のサンプル問題を解き、出題形式に慣れる
  • 模擬試験で弱点を洗い出し、補強する
  • 受験する

ACE 試験の概要

試験時間2時間
問題数・形式50〜60問。単一選択と複数選択
言語日本語で受験できる（ほかに英語、スペイン語、ポルトガル語）
受験料125米ドル（税別）
受験方法オンライン監視型、またはテストセンター
有効期間3年
推奨経験GCP の実務経験 6か月以上（受験資格の条件ではない）

出題分野（4つ）

  1. クラウド ソリューション環境のセットアップ（Set up a cloud solution environment）
  2. クラウド ソリューションの計画と実装（Plan and implement a cloud solution）
  3. クラウド ソリューションの運用の確保（Ensure successful operation of a cloud solution）
  4. アクセスとセキュリティの構成（Configure access and security）

分野ごとの配分と詳しい出題範囲は、公式の試験ガイドを確認する。上の情報は 2026-11-18 時点の公式ページによる。
